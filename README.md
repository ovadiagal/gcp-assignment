# GCP Assignment for CS3300

Author - Gal Ovadia
This is my submission for the GCP assignment. This spring boot application has two endpoints:

1. `/username` - Returns my GT username (govadia3)
2. `/time` - Returns the current time in HH:MM:SS format

## Running the application locally

1. Clone the repository
2. Run `mvn clean install` to build the application
3. Run `mvn spring-boot:run` to start the application locally

## Testing the application

1. Open a web browser and navigate to `http://localhost:8080/username`
2. You should see the username "govadia3"
3. Navigate to `http://localhost:8080/time`
4. You should see the current time in HH:MM:SS format
